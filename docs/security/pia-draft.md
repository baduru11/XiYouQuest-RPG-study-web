## Part 2: Data processing cycle analysis

**Flow.** A student signs in with HKUST Microsoft Entra ID. The application
(Vercel) verifies the sign-in and stores the account in Supabase (Mumbai).
Speaking exercises send the recording to iFLYTEK (Singapore) for scoring and
recognition; the recording is not stored by XiYouQuest. Feedback, study plans
and companion replies are generated by a language model reached through
OpenRouter (United States), restricted to hosts that retain no prompts, do not
train on them, and are not in mainland China. Results are stored in Supabase.
Students can download or delete their data from the Profile page.

**Types of personal data.** Name, HKUST email address and profile picture (from
single sign-on); display name, friend code, levels and experience points;
practice attempts and scores, pronunciation scores, mock-exam results and AI
feedback; study plans; companion chat messages and speech transcripts; avatar
images; session IP address and browser; security log of sign-ins, refused
sign-ins, exports, deletions, avatar uploads and rate-limit refusals. No HKID,
passport, date of birth, phone number or biometric template is collected;
voice recordings are processed transiently for scoring and not retained by the
application.

**Estimated number of data subjects.** 28 accounts on 2026-09-24. **[Expected
population: which courses or cohorts will be invited?]**

**Data processors and safeguards.**

| Processor | Data | Safeguards |
|---|---|---|
| Supabase (database, storage, edge functions) | All stored data | DPA with 48-hour breach notice and deletion after termination; encryption at rest; database roles reachable by clients hold no privilege; TLS verified with a pinned CA and enforced by the database since 2026-09-25 |
| Vercel (web hosting) | All requests | TLS 1.2+; security headers; SOC 2 Type 2 available on request |
| iFLYTEK Open Platform (SYNLAN Technology, Singapore) | Voice recordings and practice text | Transient processing; credentials held server-side; no DPA (OA-13) |
| OpenRouter and selected model hosts | Practice results, chat messages and transcripts needed for feedback | Zero data retention, no training, no hosts in mainland China; student ids stripped from prompts |

**Transfers outside Hong Kong.** Yes: India (Supabase), the United States
(Vercel, OpenRouter, most model hosts), Singapore (iFLYTEK), and Spain or other
regions for some model hosts. Purpose: operating the service. All are
disclosed in the privacy notice.

## Part 4: Potential risks and mitigation

| Risk | Mitigation | Residual |
|---|---|---|
| Unauthorised access to another student's records | Session-scoped queries (tested per route); client roles hold no privilege; posture check weekly | Low |
| A full-access database credential misused | The legacy JWT signing secret was revoked and the legacy API keys disabled on 2026-09-26 (OA-1); the app holds only the new secret key and a least-privilege database role (OA-16) | Low; the database owner password should still be rotated (OA-9) |
| Other students see names and performance | Disclosed in the notice | Open: visibility decision (OA-10) |
| Voice data processed by a provider without a DPA | Transient processing in Singapore; disclosed | Open: OA-13 |
| Chat and transcripts reach a language model | Zero data retention, no training, no mainland-China hosts; ids stripped | Accepted pending DPO view |
| Loss of data (no backups) | None today | Open: OA-3 |
| Account taken over through a reassigned HKUST address | Tenant and signature pinning | Open: OA-11 |
| Practice score mistaken for an official PSC result | Prompts and labels state practice status | Low |
